# Roadmap / 路线图

OSS Goldmine should stay small, evidence-first, and screenshot-friendly.

开源金矿应该保持小、证据优先、适合截图传播。

## V0.1 / Current MVP

- GitHub topic search / GitHub 方向搜索
- Demand Gap Score / 需求缺口分
- Sample opportunity cards / 样例机会卡
- Live GitHub repository search / 实时 GitHub 仓库搜索
- Optional GitHub token / 可选 GitHub token
- Copy AI Build Plan / 复制 AI 开工计划

## V0.2 / Evidence Upgrade

- Cluster top open issues / 聚类高价值 open issues
- Separate bugs, feature requests, install problems, and stale PRs / 区分缺陷、功能请求、安装问题、过期 PR
- Add competitor check links / 加入竞品检查链接
- Add shareable card image export / 导出可分享机会卡图片

## V0.3 / Builder Workflow

- Save opportunity cards locally / 本地保存机会卡
- Generate README starter / 生成 README 初稿
- Generate launch post draft / 生成发布文案
- Add CLI mode / 增加 CLI 命令行模式

## Non-goals / 暂不做

- No repo shaming / 不羞辱维护者
- No cloning recommendations / 不鼓励复刻完整项目
- No login or hosted user data in early versions / 早期不做登录和托管用户数据
