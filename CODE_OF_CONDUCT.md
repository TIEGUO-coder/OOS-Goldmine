# Code of Conduct / 行为准则

## Our Standard / 我们的标准

OSS Goldmine should be useful without being hostile.

OSS Goldmine 应该有用，但不应该带有攻击性。

We welcome:

我们欢迎：

- Respectful disagreement / 尊重式分歧
- Evidence-based feedback / 基于证据的反馈
- Better scoring ideas / 更好的评分想法
- False-positive reports / 误判反馈
- Contributions that respect original maintainers / 尊重原维护者的贡献

We do not welcome:

我们不欢迎：

- Harassment or personal attacks / 骚扰或人身攻击
- Maintainer shaming / 羞辱维护者
- Encouraging people to clone or exploit projects without attribution / 鼓励无署名复刻或利用项目
- Publishing private tokens, credentials, or sensitive data / 发布私人 token、凭据或敏感数据

## Maintainer Respect / 尊重维护者

This project uses language like:

本项目使用这样的表达：

- maintenance is fading / 维护正在变慢
- demand is still alive / 需求仍然活跃
- companion tool / 配套工具
- adaptation opportunity / 改造机会

Avoid language like:

避免这样的表达：

- dead repo / 死仓库
- steal this idea / 偷这个点子
- abandoned by lazy maintainers / 被懒惰维护者抛弃

## Enforcement / 执行

Maintainers may remove comments, issues, or pull requests that violate this standard.

维护者可以移除违反本准则的评论、issue 或 PR。
