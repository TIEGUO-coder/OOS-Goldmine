# Code of Conduct

## Our Standard

OSS Goldmine should be useful without being hostile.

We welcome:

- Respectful disagreement
- Evidence-based feedback
- Better scoring ideas
- False-positive reports
- Contributions that respect original maintainers

We do not welcome:

- Harassment or personal attacks
- Maintainer shaming
- Encouraging people to clone or exploit projects without attribution
- Publishing private tokens, credentials, or sensitive data

## Maintainer Respect

This project uses language like:

- maintenance is fading
- demand is still alive
- companion tool
- adaptation opportunity

Avoid language like:

- dead repo
- steal this idea
- abandoned by lazy maintainers

## Enforcement

Maintainers may remove comments, issues, or pull requests that violate this standard.
