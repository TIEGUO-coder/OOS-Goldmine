# Contributing

Thanks for helping improve OSS Goldmine.

## Good First Contributions

- Add better scoring signals
- Improve issue clustering
- Add high-quality opportunity examples
- Improve README wording or screenshots
- Report false positives

## What Makes a Good Opportunity Card

A strong card should explain:

- Why demand is still alive
- Why maintenance appears to be slowing
- What existing alternatives already solve
- What small wedge is still worth building
- Why this respects the original maintainers

## Development

```bash
npm install
npm run dev
npm run build
```

## Pull Requests

Please keep changes focused. A useful pull request should include:

- Clear before/after behavior
- Reasoning for scoring changes
- Sample repos used for testing
- Screenshots for UI changes

## Tone

OSS Goldmine should never shame maintainers.

Use respectful language:

- Good: maintenance is fading
- Good: demand is still alive
- Good: companion tool
- Avoid: dead repo
- Avoid: steal this idea
