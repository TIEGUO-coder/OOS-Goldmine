# Opportunity Card Template

Use this format for each daily OSS Goldmine card.

## Title

One plain-English startup opportunity.

Example:

```text
A lightweight Postman migration helper
```

## Source Repo

Repository:

```text
owner/repo
```

URL:

```text
https://github.com/owner/repo
```

## Verdict

Choose one:

```text
Build / Watch / Kill
```

## Why Now

Explain the demand in one or two plain sentences.

Do not say only "the repo is old."

## Who Might Care

Name a specific user group.

Example:

```text
API-heavy dev teams leaving legacy tools.
```

## First Tiny Test

Describe the smallest useful thing to test in 48 hours.

## Evidence

```text
Stars:
Open issues:
Quiet months:
Repeated themes:
Alternatives:
```

## Do Not Build

Write what the builder should avoid.

Example:

```text
Do not build a full Postman clone.
```

## Agent Prompt

```text
Turn this opportunity card into a 3-day build plan.
Keep the first version narrow.
Do not recommend cloning the source repo.
```
