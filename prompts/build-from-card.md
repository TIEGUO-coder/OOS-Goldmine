# Turn A Card Into A Build Plan

Use this after you save one OSS Goldmine card.

```text
Read the selected OSS Goldmine opportunity card.

Selected card:

[paste card title or JSON object here]

Task:
Turn this into a practical 3-day build plan.

Include:
1. What the first version should do
2. What it should not do
3. Input and output examples
4. Data or fixtures needed
5. Suggested tech stack
6. README positioning
7. Demo script
8. Launch post angle

Rules:
- Do not build a full clone of the source project.
- Keep the first version small enough for a solo builder.
- Make the result useful even if the original repo still exists.
- Focus on a painful workflow, not a broad product category.
```
